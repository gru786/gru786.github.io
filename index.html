About Me

Philosophy, engineering focus, and background

Hi, I’m Gaurav Singh. I am a software engineer dedicated to creating high-performance, clutter-free mobile applications.

I focus on intentional software architecture — prioritizing user privacy, instant startup performance, and intuitive UI interactions over unnecessary complexity. My work spans personal finance tools with zero-friction entry, focus timers, mental health audio apps, and casual arcade games.

Every app is built with a deep emphasis on responsiveness, clean visual hierarchy, and practical everyday utility.
